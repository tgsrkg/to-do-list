# Todo List

Простой список задач, разработанный на **React + TypeScript** с использованием **Vite**.

## Возможности

- Добавление новых задач.
- Отметка задач как выполненных и возможность вернуть их в активное состояние.
- Удаление задач.
- Фильтрация задач: все, активные и выполненные.
- Сохранение задач в `localStorage`.
- Переключение между светлой и тёмной темами.
- Сохранение выбранной темы после перезагрузки страницы.
- Запрет добавления пустых задач.

## Технологии

- React
- TypeScript
- Vite
- CSS
- localStorage

## Установка и запуск

Для запуска проекта необходимо установить [Node.js](https://nodejs.org/).

1. Склонируйте репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

2. Перейдите в папку проекта:

```bash
cd to-do-list
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

После запуска откройте адрес, который появится в терминале.

## Сборка проекта

Для проверки production-сборки выполните:

```bash
npm run build
```

Для локального просмотра собранного проекта:

```bash
npm run preview
```
